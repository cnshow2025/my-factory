# 貨批資料檔 — 格式與產生方式

模擬器的「📥 實際貨批分析」可以載入一份 xlsx，用真實的 WIP 跑排程，一路跑到最後一批做完為止。

## 兩個檔案

| 檔案 | 用途 |
|---|---|
| `../待測貨批_填寫範本.xlsx` | 空白範本。三個分頁：說明／貨批／機台，附欄位說明與範例列 |
| `../模擬WIP_200批.xlsx` | 200 批的模擬資料，格式相同，可直接載入試跑 |

## 檔案結構

載入時只讀「貨批」與「機台」兩個分頁，其餘分頁不影響模擬。

### 貨批

| 欄位 | 必填 | 說明 |
|---|---|---|
| `lot_id` | ✔ | 批號，不可重複 |
| `package` | ✔ | 封裝／Kit 代號。**同代號＝同一套 Kit**，換到不同代號才要換 Kit |
| `program` | ✔ | 測試程式。package 相同但 program 不同＝只換程式 |
| `qty` | ✔ | 顆數 |
| `tpu_sec` | ✔ | **單一 site 測一顆**的秒數（不是整批時間，也不是多 site 的等效時間） |
| `arrive_h` | | 到廠時間，以「現在」為 0 的小時數。空白＝已在 WIP |
| `due_h` | | 交期，同樣以現在為 0 的小時數。空白＝這批不看交期 |
| `hot` | | `Y`＝急件，可插單 |
| `yield_pct` | | 實際良率。空白＝用參數的隨機區間 |
| `note` | | 備註，不影響模擬 |

### 機台

| 欄位 | 必填 | 說明 |
|---|---|---|
| `machine_id` | ✔ | 機台名稱 |
| `sites` | ✔ | site 數，直接當速度倍率 |
| `kit_now` | | **現在機台上裝著的 Kit**。空白＝空機，第一批要先換 Kit |
| `prog_now` | | 現在載入的程式 |
| `can_packages` | | 能測的封裝，用 `\|` 分隔。空白＝全部都能測 |
| `available_at_h` | | 幾小時後才空出來（保養中、在跑別的貨）。空白＝現在就能用 |

### 能力矩陣（只有 `模擬WIP_200批.xlsx` 有）

機台 × 封裝的對照表，一眼看出哪台機能測哪種封裝、現在身上裝著什麼 Kit。
打勾來自「機台」分頁的 `can_packages`，黃底格是該台目前裝著的 Kit。

底下五列是產能對不對得上貨量的檢查（都是公式，改資料會跟著變）：

| 列 | 意思 |
|---|---|
| 能測這種封裝的機台數 | 有幾台機「可以」測 |
| 能測這種封裝的 site 合計 | 這些機台的 site 加總 |
| 目前正裝著這種 Kit 的 site | 機隊此刻停在什麼配置 |
| 這批貨的工時（分，1 site） | 這種封裝的貨有多少工作量 |
| **若完全不換 Kit，要跑幾小時** | 工時 ÷ 目前裝著的 site |

最後一列是重點。哪一種明顯偏高，就是這批貨的瓶頸 —— 它的量和現在裝著它的 site 數對不上，
排程如果一味省改機、不肯換 Kit，就會卡在那一種上面，其他機台只能閒著。

以內附的 200 批資料為例：

| | QFN48 | QFN32 | SOP16 | TSSOP28 | BGA144 |
|---|---|---|---|---|---|
| 目前裝著的 site | 40 | 22 | 16 | 12 | 10 |
| 工時（分） | 8,422 | 9,293 | 4,304 | 1,825 | 212 |
| 不換 Kit 要跑 | 3.5 h | **7.0 h** | 4.5 h | 2.5 h | 0.4 h |

QFN32 的量最大，裝著它的 site 卻只有 22 —— 全機隊平均攤平只要 4.0 小時，它一種就要 7.0 小時。

**這頁是對照用的，模擬器讀的仍然是「機台」分頁的 `can_packages`；改這頁不會改變模擬結果。**

## 其他

`package` 與 `program` 的代號自由命名，種類數以檔案為準，不受參數面板的上限限制。
載入後機台數、site 數與能力矩陣都會改成檔案裡的設定；**工程師人數留在面板上**，
方便拿同一批貨只改人數重跑。

## 重新產生

```bash
cd docs/wip
python3 mk.py        # → ../待測貨批_填寫範本.xlsx（空白範本）
python3 gendata.py   # → ../模擬WIP_200批.xlsx（200 批模擬資料）
```

需要 `openpyxl`。`mkcommon.py` 是兩者共用的版面與欄位定義。
`gendata.py` 用固定亂數種子，重跑會得到同一份資料。
