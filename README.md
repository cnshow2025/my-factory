# MyFactory — 測試機台排程模擬遊戲

模擬測試廠排程：5 台測試機，把客戶進來的貨批派到機台上，在一天（1440 分鐘）內拚最大良品產出。
單一 HTML 檔，用瀏覽器直接開 `index.html` 就能玩，不用安裝任何東西。

## 規則

**匹配**：機台上裝的 Kit(Package) 與測試程式要和貨批一致才能開測。

| 情況 | 改機時間 |
|---|---|
| Package 同 ＋ 程式同 | 0 分鐘，直接開測 |
| Package 同 ＋ 程式不同 | 30 分鐘 |
| Package 不同 | 60 分鐘（換 Kit，含載入程式） |

**測試流程**：T1 測全批（時間 = 數量 × 單顆秒數）→ 良率隨機 80~99% → 未達 99% 時 fail 品進 RT1（只測 fail 顆數）→ 累積良率仍未達 98% 再進 RT2 → 完成出貨。Retest 不用改機，但照樣佔機台時間。

**當機**：每台機每小時有機率故障，修復 10~120 分鐘隨機，修好後從中斷處續測。

**交期報價規則**（參數面板可選，四種）：
| 規則 | 交期算法 |
|---|---|
| 工時比例制 | （預估工時 ＋ 一次換 Kit）× 寬鬆倍數 |
| 批量分級固定時數 | 小／中／大批各自承諾固定時數，與實際工時無關 |
| 統一固定時數 | 不分批量一律同樣時數 |
| 工時＋固定緩衝 | 預估工時 ＋ 固定緩衝時數 |

HOT 批的承諾時間再乘上「HOT 交期倍率」。換規則不會改變產生的貨批（亂數流刻意保持一致），所以四種規則可以在同一批貨上直接對比。

**交期與優先批**：預估工時＝T1 加 30% retest 餘裕，再加一次換 Kit 的時間，所以長批的餘裕也按比例放大。約 18% 的批是 **HOT 優先批**，交期短很多。WIP 卡顯示交期時刻與剩餘時間，剩不到 2 小時轉黃、逾期轉紅，列表可切換「依交期／依到貨」排序。

**預約排隊**：機台在忙也可以先把貨批放上去排隊，每台最多 4 批。預約的批從 WIP 移到機台卡下方的「待接」區依序列出，現批一做完就自動接上，需要改機也會自動開始改。每個待接項會標出接上去要不要改機、要幾分鐘，把同 Package 的批排在一起就能省掉換 Kit 的一小時。待接區可用 ↑ 調順序、✕ 退回 WIP，或用標題列的「整批移轉 ↦」把整串待接批一次搬到指定的另一台機（例如原機當機了）。目標機放不下時會只搬移得下的部分，其餘留在原機。

**插單**：選到 HOT 批時，正在測試的機台會出現「⚡插單」按鈕。插單會把原本那批退回 WIP 且**已測進度全部歸零**（要重測 T1），改機時間照算。

**到貨**：開局先有幾批，之後整天分批進 WIP。

**計分**：只有當天完成的批才計良品顆數（在製中的不算）。

- HOT 批**準時**完成，良品算 1.5 倍
- 逾期出貨、或收工時還沒完成而交期落在當天內的批，每批固定扣 5000 分，HOT 扣雙倍

`分數 = 計分良品 × (1 + 稼動率 × 加權) − 逾期扣分`

## 畫面

每張機台卡左邊是測試機圖示外圈的**圓環進度**，顯示現批（或改機、修機）跑到幾 %，顏色跟著狀態走；卡片中段是現批資訊；下方是**今日稼動時間軸**——整條代表一天 1440 分鐘，用顏色畫出這台機每個時段在測試（綠）、Retest（紫）、改機（黃）、當機（紅）還是閒置（灰），白線標示現在跑到哪裡。滑過時間軸會在下方讀出那個時段在做什麼——測哪一批（`T1 L018`、`RT1 L011`）、改機換去哪個組合（`改機 → C/P8（準備 L016）`）、當機時哪一批被暫停——並用藍線標出游標位置。游標位置存在遊戲狀態裡，所以遊戲跑動中重畫也不會閃掉。整張卡片的底色也跟著狀態變（測試綠／Retest 紫／改機黃／當機紅並脈動／閒置灰）。

收工結算畫面除了分數與各機台明細，還有**五台機一整天的稼動時間軸總覽**，以及**全廠時間結構**——把 5 台機 × 1440 分鐘拆成測試／Retest／改機／當機／閒置各佔幾 %，一眼看出當天產能被什麼吃掉。

## 手機

**直向＝精簡模式**：左邊貨批、右邊機台並排，只留顏色與關鍵數字（機台代號、狀態色、圓環進度、剩餘時間、Kit／程式、可測封裝），事件記錄、時間軸、待接佇列、改機按鈕、參數與跑分面板都收起來，方便單手把貨批放到機台上。機台卡右下角有一個角標顯示**有幾批在排隊等這台機**（佇列裡有 HOT 批時角標轉紅並標示），因為完整的待接清單在直向是收起來的。**橫置就回到完整版**。

**拖曳派工**：手指按住貨批往右拖（垂直滑動仍然是捲動清單，不會誤觸），拖曳時相容的機台會亮起並顯示要花的改機時間，放開即派工；機台在忙就進它的待接佇列，不能測該封裝的機台外框顯示紅色並拒絕。點選派工（點貨批再點機台）同樣可用。

## 操作

- 點左側貨批選取 → 機台卡亮起並在右上角顯示要花的改機時間 → 點機台卡即派工；機台在忙時點下去就是排進它的「待接」佇列（角標會顯示「排隊 #n」與接上去的改機時間）。
- 閒置機台可用卡片下方的 **改機** 先把 Kit／程式換好卡位。
- `▶ 開始` / 空白鍵暫停續跑，速度 1x / 2x / 4x。一局預設 5 分鐘跑完一天。

## 排程演算法平台

「排程演算法」面板可以讓模擬器自己派工，並且比較不同排程法則的優劣。

**可重現情境**：改用種子亂數，同一個「情境種子」會產生完全相同的貨批序列、良率與當機時間點，所以不同策略是在同一天上對打，差異來自策略本身而不是運氣。

**內建策略**
| 策略 | 規則 |
|---|---|
| FIFO | 到貨順序，基準線 |
| EDD | 最早交期優先 |
| SPT | 最短工時優先 |
| HOT → EDD | 優先批一律插前面，其餘照交期 |
| Setup-aware | 優先挑不用改機的批串在同一台機，同成本再比交期 |
| Composite | 交期緊迫度／改機成本／批量／HOT 四因子加權，權重可用滑桿調 |

**自動派工行為**：預約深度（0＝做完才決定，1~3＝先押幾批）、是否允許 HOT 插單。

**批次跑分**：所有策略 × N 天（預設 20，種子 1~N）秒級跑完，輸出策略比較表（平均／最低／最高分數、平均良品、準時率、稼動率、改機分鐘、逾期批數）與每日分數分佈圖（同一天各策略配對比較，滑過去看逐日對照，點圖例可單獨顯示某策略）。

## 參數

**機台能力矩陣**：參數面板裡可以勾選每台機台能測哪些封裝（某產品只能在某些機台生產）。取消勾選後，派工、預約、改機、插單、整批移轉都會被擋下，自動排程也不會把那種封裝派給它；機台卡會標出「可測 A·B·C」，選到它測不了的批時角標顯示「不可測 X」。沒有任何機台能測的封裝，不會產生貨批。

「背景參數」面板最上面是**參數組（preset）**：`遊戲預設` 是平衡過的遊玩參數，`我的工廠` 是對應真實產線的參數組（5 台測試機、封裝 5 種、測試程式 8 種、批量結構 小批 0.5~2k 占 60%／中批 2~10k 占 30%／大批 10~25k 占 10%、單顆 2 秒、換 Kit 60 分、換程式 30 分、良率 80~99%、RT 門檻 99/98、Retest 救回率 60%、當機率 5%/小時、HOT 比例 10%、逾期一批扣 20,000 分、一天 24 小時三班）。把面板裡的數字改成你現場的條件後按「💾 存成『我的工廠』」，設定會存在這台瀏覽器裡，下次開啟自動帶入；跑分比較就會依你的真實條件給建議。

面板可調：一局長度、機台數、改機時間、當機機率與時長、良率範圍、retest 門檻與救回率、到貨頻率、批量與單顆測試時間、稼動率加權、封裝與測試程式種類數、每台預約上限、優先批比例、HOT 準時加成、逾期扣分、交期寬鬆倍數。批量／機台數類設定按「重新開始」後套用。
